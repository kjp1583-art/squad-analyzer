# 상준♡투이 게임천국

메인 화면(`index.html`)은 게임 선택창이다. 새 게임은 폴더를 하나 만들고 `index.html` 의 `GAMES` 배열에 한 줄을 더하면 카드가 생긴다.

| 폴더 | 게임 |
|---|---|
| `match/` | 멍냥 카페 (동물 매치3, 둘이 같이하기, 3단계마다 꽃 축제) |
| `mango/` | 망고게임 (베트남 과일 합치기 · 방 코드로 둘이서 온라인 대결: 먼저 망고 완성 또는 더 오래 버티기) |
| `marble/` | 여행마블 (한국·베트남 명소 부루마블 · 방 코드로 둘이서 온라인 / 혼자 컴퓨터랑 · 방장 쪽이 규칙을 돌리고 상태를 뿌린다) |
| `uno/` | 멍냥 우노 (우노 카드게임 · 동물이 색 · 방 코드로 둘이서 온라인 / 혼자 컴퓨터랑 · 방장이 규칙을 돌리고 상대에겐 장수만 보낸다) |
| `topik/` | 박상준 한국어능력시험 (읽기 17 + 어휘·문법 39문항, 랜덤 20문제 모드, 베트남어 도움말) |

- 공용 코드: `shared.js` (이름, 기기 식별자, Supabase 연결, 배경음악)
- 랭킹: Supabase 함수 `game_submit` / `game_ranks` (게임마다 `game` 식별자가 다르다)
- 그림은 `img/` (캐릭터, 과일, 메인 화면 카드 그림)
- 주소: https://kjp1583-art.github.io/squad-analyzer/meongnyang-cafe/

## 작업 규칙 (상준 지시)
- 2026-10-26 "머지는 너가 알아서 해 이제부터": 이 폴더(`meongnyang-cafe/`)의 변경은 Claude 가 PR 을 만들고 직접 머지한다. 이 폴더 밖(클랜 사이트·분석기)은 건드리지 않는다.
- 메인 화면 게임 카드는 글자 설명보다 **실제 게임 화면**을 쓴다(무슨 게임인지 바로 알 수 있게).
- 동물 4마리(푸들·고양이·카피바라·개구리)는 여러 게임에 나오는 메인 캐릭터다.
- 퀴즈 지문에는 상준이 직접 알려 준 사실만 쓴다.

## 멍냥 카페 꽃 축제 (2026-10-26 기획안 A+B+C, 3단계마다)
- 단계가 3의 배수이면 동물이 꽃으로 피어난다(해바라기 푸들·복숭아꽃 고양이·벚꽃 토끼·국화 곰·매화 병아리·장미 돼지·연꽃 카피바라·수련 개구리).
- 목표는 점수가 아니라 그 단계의 꽃 모으기(예: 푸들 해바라기 10송이, 둘이면 20송이).
- 개화: 터지는 칸 옆의 꽃이 봉오리 → 반개 → 만개로 자란다. 만개한 꽃이 터지면 꽃잎 폭죽(+모양 5칸).
- 나비 블록(4개 맞추기)·꽃다발 블록(5개 맞추기)이 십자·무지개 블록 대신 나온다.
- 클리어하면 꽃다발 선물 화면이 나온다.
