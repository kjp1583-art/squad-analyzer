# 💔 멘헤라 태웅 원화 자리

여기에 **원본 그대로** 올려 주세요 — 파일명 `_src.png`
(말풍선·하트·낙서가 있는 채로 올리셔도 됩니다. 봇이 쓰는 `front.png` 는 제가 여기서 만들어 넣습니다.)

- 업로드: 이 폴더에서 **Add file → Upload files**
- 규격: 정사각형 PNG (1024 이상 권장). 배경은 있어도 됩니다 — 누끼는 자동으로 땁니다.
- 처리: 배경 제거 → 말풍선·하트·낙서 제거 → 768×768 RGBA `front.png` 로 저장
  + 같은 그림으로 🎖 스킨(`skins/boss_tw/front.png`)도 만듭니다.
