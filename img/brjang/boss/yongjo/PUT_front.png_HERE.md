# 여기에 `front.png` 를 넣어주세요

이 폴더가 **🐲 용조련사** 의 원화 자리입니다.

1. 이 페이지 우측 상단 **Add file → Upload files** (또는 파일을 창에 그대로 드래그)
2. 파일 이름은 반드시 **`front.png`**
3. Commit changes

올리고 나면 이 안내 파일은 지워도 됩니다. 봇 쪽은 이미 붙어 있어서
다음 출현부터 공지에 큰 이미지로 나옵니다(파일이 없으면 지금처럼 벡터 그림).
