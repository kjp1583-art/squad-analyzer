# 흐접새우 4인 파티 레이드 — 사장님용 요약

(2026-10-08 개정 · 비판 검토 3건 반영 · 자세한 기술 내용은 `DESIGN.md`, 아이폰 확인은 `IPHONE_CHECKLIST.md`)

## 먼저, 8줄 요약

1. 솔로 게임이 "꺼지는" 건 웹 탓이 아니라 **판을 폰 메모리에만 들고 있어서**입니다. 새로고침하면 처음부터라는 건 제가 확인했습니다. 아이폰이 얼마나 자주 페이지를 버리는지는 **아직 모릅니다**.
2. "웹 팝업창"의 정체는 아직 가설입니다. 가장 유력한 건 **게임을 열자마자 디스코드 로그인 확인 화면을 잠깐 다녀오는 기능**이 아이폰 홈 화면 앱에서 별도 창으로 열리는 경우입니다(코드로 좁힌 추측, 재현은 못 함).
3. 레이드는 **서버가 게임 계산을 맡습니다.** 앱을 잠깐 나갔다 와도 같은 판에 다시 붙습니다 — 단 **15초 안의 짧은 이탈만 보호**됩니다. 45초가 넘으면 쓰러진 걸로 처리되고, 서버가 죽거나 교체되면 진행 중인 판은 사라집니다.
4. 서버는 따로 둡니다. 1순위 Vultr **서울** 월 $5(약 6,700원), 2순위 Vultr **도쿄** 월 $5. **도메인 구입이 필수**입니다(연 만원대로 알려짐, 가격은 확인 못 함). Fly.io 는 이번 검토에서 **뺐습니다**.
5. 레이드 화면은 **레이드 서버가 직접 줍니다.** 솔로 게임을 하루에도 여러 번 고쳐도 레이드가 깨지지 않게 하려는 구조입니다. 대신 레이드 주소에서 **디스코드 로그인을 한 번 더** 하셔야 합니다.
6. 일정은 정정합니다. 이전에 말씀드린 "약 15세션"은 **틀렸습니다.** 다시 합산하니 **약 40~59세션**입니다. 그래서 중간에 사람이 해 볼 수 있는 **공동 호드 알파**와 **진행/중단 점검 3곳**을 넣었습니다.
7. 가장 큰 일은 "다른 사람 캐릭터와 이펙트를 내 화면에 그리는 일"입니다. 아직 손도 못 댔습니다. 보스 체력 등 밸런스 숫자는 전부 초안입니다.
8. 지금 해 주실 일: **폰 기종 한 줄, "웹 팝업창" 스크린샷 한 장, 아이폰 확인표 1차**(20~30분, 나눠서 해도 됩니다).

## 1. 지금 겪으시는 문제

**확실한 것**
- 지금 솔로 게임은 하던 판을 폰 메모리에만 들고 있고 어디에도 저장하지 않습니다. 폰 크기 브라우저에서 20초 하다가 화면을 숨기고 새로고침하면 **타이틀 화면**으로 돌아가는 걸 제가 확인했습니다.
- 다만 이건 "새로고침하면 처음부터"라는 사실일 뿐입니다. **아이폰이 이 시간 안에 페이지를 실제로 버리는지는 못 봤습니다** → 확인표 1번으로 확인합니다.

**아직 모르는 것 — "웹 팝업창"**
- 코드를 보니 흐접새우는 열자마자 "로그인이 곧 만료되는 사람"을 디스코드 확인 화면으로 잠깐 보냈다가 돌아오게 합니다. 아이폰에서 홈 화면 아이콘으로 연 앱은 이런 이동을 **위에 "완료" 막대가 있는 별도 창**으로 여는 것으로 알려져 있습니다. 그러면 게임이 그 창 안에서 돌다가, 창이 정리될 때 첫 화면으로 돌아가는 증상이 사장님 설명과 맞습니다. (**가설입니다. 재현은 못 했습니다.**)
- 그래서 "홈 화면 앱처럼 만들기"는 **확인표 4·5번 결과를 보고 나서** 하기로 했습니다. 원인이 이것이라면 홈 화면 앱화가 오히려 증상을 늘릴 수 있기 때문입니다.
- 사장님이 보신 화면의 **스크린샷 한 장**이면 가설이 맞는지 바로 가려집니다. 위에 "완료/Done" 막대가 있었는지가 핵심입니다.

**해결 방향**
- 솔로: "이어하기"(판 저장)를 따로 만들면 줄어듭니다. 다른 작업(#12)이 이미 하고 있습니다.
- 레이드: 서버가 판을 들고 있어서 폰이 판을 못 지켜도 같은 판에 다시 붙습니다. 레이드는 **디스코드 로그인 확인 화면을 거치지 않고** 복귀하도록 만듭니다.

## 2. 레이드는 이렇게 만듭니다 (한 장 요약)

- **솔로는 그대로.** 밀려오는 적을 베는 게임은 건드리지 않습니다. 레이드는 새로 추가하는 콘텐츠입니다.
- **4명이 실시간으로 같이 싸우는 보스전.** 첫 보스는 **또뀨의 진실의 방(재판 레이드)** 을 제안합니다. 한 판 12~13분. 이번에 **첫 버전을 줄였습니다**: 역할 버튼 2종(탱커·서포터), 협동 기믹 2종(흩어지기, 감옥에 갇힌 동료 구하기). 나머지는 사람이 해 본 뒤에 추가합니다. 정원은 **2~4명 가변**(4명이 못 모여도 열 수 있게).
- **조작은 솔로처럼 한 손.** 무기는 자동으로 나가고, 손가락은 이동 + 역할 버튼 1개. 캐릭터 17명 모두 역할이 정해져 있고, **해금과 상관없이 전원 선택 가능**으로 바꿨습니다(해금을 서버가 검증할 방법이 없고, 능력치를 똑같이 맞추기 때문).
- **협동은 "움직이기"만으로 됩니다.** 구출할 때는 서버가 사람마다 기둥을 정해 주고 화면에 "네 기둥은 ②"라고 화살표로 알려 줍니다.
- **보상은 칭호·꾸미기·기록만.** 맛동산·장비·가챠는 건드리지 않습니다. 단 칭호를 저장하려면 브장신 기록 파일에 칸을 추가해야 해서, 그것도 **사장님 승인이 필요한 항목**입니다.
- **게임 계산은 서버가 합니다.** 기존 캐릭터·무기 코드를 서버에서 그대로 돌려 봤고(4명 × 5조합 × 15분, 오류 없음), 다만 **아직 "누구 무기인지" 구분이 없어 동작의 의미는 틀린 상태**입니다. 그걸 고치는 게 1단계 일입니다.

## 4. 서버는 어디에, 얼마에

- 지금 봇이 사는 곳(bot-hosting)은 **독일**입니다. 한국에서 왕복 약 0.23초라 실시간 전투에는 느립니다(제3자 자료, 폰 실측 아님). 봇 메모리도 여유가 없습니다.
- 그래서 **레이드 전용 작은 서버를 따로** 둡니다. 서버가 레이드 화면 파일도 함께 내려 줍니다.
  - 1순위: Vultr **서울**, 월 **$5(약 6,700원)**.
  - 2순위: Vultr **도쿄**, 월 $5(같음). 서울이 느리거나 재고가 없을 때.
  - ~~Fly.io 도쿄~~: 공식 문서를 확인하니 싼 사양은 CPU를 6.25%만 보장해 레이드 중 멈추고, 멈추지 않는 사양은 월 약 $33~43이라 예산을 넘습니다.
  - 어느 쪽이 나은지는 **사장님 폰으로 잰 숫자**로 정합니다.
- **도메인은 필수**입니다(서버 주소·디스코드 로그인 복귀 주소가 고정이어야 해서). 연 만원대로 알려져 있지만 **가격은 확인 못 했습니다.**
- 월 합계: **$5 + 도메인**. 방이 늘어 서버를 키우면 $15(약 20,000원)까지. 예산 1~2만원 안입니다. 해외 카드 수수료는 확인 못 했습니다. Vultr 는 **서버를 꺼 두기만 해도 과금**되고(삭제해야 멈춤), 한 달 최대 672시간 기준입니다.
- 봇은 10분마다 **확인해서 코드가 바뀌었을 때만** 재시작합니다(이전 요약의 "10분마다 재시작"은 부정확했습니다). 레이드 서버는 봇과 분리되어 있어서 봇이 재시작해도 진행 중인 판은 안 끊깁니다.

## 6. 사장님이 하실 일

**지금 바로**
1. **폰 기종과 iOS 버전** 한 줄(설정 → 일반 → 정보).
2. **"웹 팝업창" 스크린샷 한 장.** 위에 "완료/Done" 막대가 있었는지가 핵심입니다.
3. `IPHONE_CHECKLIST.md` **1차**(20~30분, 여러 번에 나눠도 됩니다). 특히 **홈 화면 앱을 열 때 위에 "완료" 막대가 뜨는지**와 **로그인이 되는지**.
   (핑 시험 페이지와 소켓 시험 페이지는 제가 아직 안 만들었습니다. 만들면 링크를 드립니다.)

**숫자가 좋게 나오면**
4. **Vultr 서버를 직접 만들기(권장, API 키가 필요 없는 방법).** 가입(카드 연결은 소액 충전 없는 "$0.00 deposit" 방식이 있다고 문서에 나옵니다) → 서울 위치, 가장 싼 $5(1GB) 사양으로 서버 1대 생성 → 제가 드리는 설정 글(스타트업 스크립트)을 붙여 넣기. 정확한 화면 순서는 가입하실 때 화면 스크린샷을 주시면 맞춰서 안내하겠습니다(저는 Vultr 화면을 직접 볼 수 없습니다).
   - *이전 안내 철회*: "GitHub 비밀 금고에 `VULTR_API_KEY` 로 넣기"는 **하지 않습니다.** GitHub 비밀 금고는 자동 실행(Actions)만 읽을 수 있는데 이번 단계에서는 Actions 를 돌리지 않습니다. 또 Vultr 키는 서비스별로 권한을 나눌 수 없어 계정 전체 권한이고, 접근 제어(허용 IP 목록)가 걸려 있을 수 있습니다. 정 키를 쓰셔야 한다면 채팅에 붙이지 말고 **에이전트 환경 설정의 비밀/환경 변수**에 넣어 주세요.
   - 제 작업 환경은 **외부 주소 접속이 막혀 있을 수** 있고 서버로 직접 접속(SSH)은 막혀 있습니다. 서버 주소를 알려 드리면 **환경 설정의 "허용 도메인"에 추가**를 부탁드릴 수 있습니다.
5. **도메인 구입.**
6. (2단계 때) 디스코드 개발자 페이지에서 **레이드 주소를 "로그인 후 돌아올 주소"로 추가 등록.**

**나중에**
7. 디스코드 모집 글 채널 정하기, 대사 초안 OK/빼기, 시험 플레이를 같이 해 줄 클랜원 3~4명(**아이폰 쓰는 분 1~2명 포함**), 보상 연결 여부 결정.

가입·결제·도메인·디스코드 설정 말고는 서버 설정, 프로그램 설치, 코드, 배포 모두 제가 합니다.

## 7. 앞으로의 순서와 크기 (정정)

이전에 "약 15세션"이라고 했던 건 **틀렸습니다.** 같은 설계서의 엔진 변경표를 행마다 합산하면 엔진만 24~37세션이라, 다시 계산했습니다. "세션"은 에이전트 작업 횟수에 대한 제 어림짐작이고, 비슷한 줄을 연달아 고치는 일은 한 번에 묶일 수 있어 **실제로는 줄 수 있습니다**(근거는 없고, 점검 때 실측으로 다시 추정합니다).

| 단계 | 하는 일 | 세션 | 끝났을 때 보이는 것 |
|---|---|---|---|
| 0 | 폰 지연 측정, 서버 계산 속도 측정, **아이폰이 백그라운드에서 연결을 얼마 만에 끊는지 측정**, 아이폰 확인 | 3~4 | 지연 숫자, 서버 위치 결정 |
| 1A | 게임 코드를 "여러 명" 구조로 바꿈(솔로가 안 깨지는지 자동 시험) | 11~17 | **눈에 보이는 변화 없음**(솔로 그대로) |
| 1B | 서버와 화면 최소 동작. **먼저 무기 2종만 그려 보고 점검** | 7~11 | 2명이 같은 적을 보며 싸우는 화면 |
| 알파 | **공동 호드**: 역할·기믹 없이 2~4명이 5분 같이 싸움 | 3~4 | **클랜원이 처음 해 보는 시점** |
| 2 | 방 만들기·초대·준비·재접속·로그인 | 4~5 | 초대 링크로 입장 |
| 3 | 또뀨 레이드(줄인 판) + 사람 시험 | 10~15 | 또뀨 레이드 |
| 4 | 칭호·기록 보드·보상(승인 필요) | 2~3 | 기록 보드 |
| 합계 | | **약 40~59** | |

**진행/중단 점검 3곳** — 사장님이 계속/축소/중단을 정합니다.
- **점검 A (0단계 끝)**: 폰 지연과 아이폰 연결 끊김 실측. 수치가 설계와 크게 다르면 설계를 고친 뒤 시작합니다.
- **점검 B (1B 중간, 무기 2종 시제품 직후)**: 가장 큰 일(다른 사람 화면 그리기)의 실제 크기를 재고 일정을 다시 잡습니다.
- **점검 C (알파 끝)**: 클랜원이 해 보고 "또 하고 싶다"가 나오는지, 인원이 모이는지.

사장님께 약속드리는 범위는 **점검 B 까지(약 18~27세션)** 입니다. 그 뒤는 점검 때 다시 정합니다.

## 8. 솔직하게 모르는 것

- 아이폰이 앱을 나갔을 때 **연결을 몇 초 만에 끊는지**, 페이지를 얼마나 자주 버리는지(실기기 측정 전 모름).
- 서울 서버의 **실제 폰 지연**(위 숫자는 "서울-독일 약 0.23초, 서울-도쿄 약 0.035초"라는 제3자 자료).
- 홈 화면 앱·디스코드 안 창에서의 **로그인 복귀, 소리 복구**(제 시험 환경에는 크롬만 있음).
- **클랜원이 4명 모이는지**. 공개 순위표(읽기 전용) 한 번 조회에서 상위 20줄이 가득 찼지만 그보다 더 있는지(상한)는 모릅니다. 0단계에서 최근 14일 활동 인원을 집계합니다.
- 보스 체력 등 **밸런스 숫자**는 전부 초안이고, 봇 시뮬레이션이 "재미있다"는 뜻은 아닙니다(사람 시험으로 판정).
- 4명 화면을 폰에서 그릴 때의 **성능·발열**.
- 도메인 가격, 해외 카드 수수료.
- 안드로이드 앱 껍데기(스토어 앱)는 나중에 선택할 수 있는 항목으로만 남겨 두었습니다.

## 9. 레이드를 기다리지 않고 지금 솔로에 넣을 수 있는 것

순서를 정했습니다. 원하시면 이 순서대로 먼저 하겠습니다.
- **바로 가능(아이폰 확인 없이)**: 손가락 두 개를 대면 조이스틱이 튀는 것 고치기, 전화 뒤 소리가 죽는 것 복구, 판 도중 화면이 꺼지지 않게.
- **아이폰에서 한 번 보고**: 노치에 점수/버튼이 가려지는 것 고치기.
- **확인표 4·5번 통과 뒤**: 홈 화면에 추가했을 때 주소창 없는 전체화면 + 앱 아이콘, "홈 화면에 추가하세요" 안내. (위 1번 가설이 맞다면 먼저 하면 증상이 늘 수 있어서 뒤로 미뤘습니다.)
- **가설이 확인되면**: 게임 시작 때의 자동 로그인 이동을 줄이기.
- 판 저장 "이어하기"(별도 작업 진행 중).
