# 흐접새우 4인 파티 레이드 — 사장님용 요약

(2026-10-08 · 자세한 기술 내용은 `DESIGN.md`, 아이폰 확인은 `IPHONE_CHECKLIST.md`)

## 1. 먼저, 지금 겪으시는 문제

"다른 화면 갔다 오면 게임이 꺼지고 키아트 화면으로 돌아간다"는 **웹이라서가 아닙니다.**
지금 솔로 게임은 하던 판을 폰 메모리에만 들고 있습니다. 폰이 메모리가 모자라면 안 보이는 페이지를 통째로 버리고, 돌아오면 처음부터 다시 열립니다. 제가 폰 크기 브라우저에서 똑같이 재현했습니다(20초 하다가 화면을 숨기고 새로고침 → 타이틀 화면).

- 솔로: "이어하기"(판 저장)를 따로 만들면 줄어듭니다. 이건 다른 작업이 이미 하고 있습니다.
- 레이드: **서버가 판을 들고 있게** 만들기 때문에 이 문제가 구조적으로 없어집니다. 잠깐 나갔다 와도 같은 판으로 다시 붙습니다.

## 2. 레이드는 이렇게 만듭니다 (한 장 요약)

- **솔로는 그대로.** 밀려오는 적을 베는 게임은 건드리지 않습니다. 레이드는 새로 추가하는 콘텐츠입니다.
- **4명이 실시간으로 같이 싸우는 보스전.** 첫 보스는 **또뀨의 진실의 방(재판 레이드)** 을 제안합니다. 이미 게임에 있는 감옥 패턴과 대사("딱 3시간", "회의록")를 살릴 수 있어서입니다. 한 판 12~13분.
- **조작은 솔로처럼 한 손.** 무기는 자동으로 나가고, 손가락은 이동 + 역할 버튼 1개(자동으로 나가게 해 둘 수도 있음). 역할은 탱커·서포터·제어·딜러 4가지이고 캐릭터 17명 모두 역할이 정해져 있습니다. (요청서에는 22명이라고 되어 있었는데 코드에는 17명입니다.)
- **협동은 "움직이기"만으로 됩니다.** 흩어지기, 붙어 있기, 감옥에 갇힌 동료 구하기(기둥 두 곳을 동시에 밟기), 바닥을 순서대로 밟기.
- **전화가 와서 앱을 나가도 안전.** 15초는 몬스터가 안 때리고, 이어서 30초는 유령 상태로 보호되고, 그래도 못 오면 쓰러진 걸로 처리됩니다. 돌아오면 "지금 2페이즈, 보스 HP 38%" 요약 카드가 뜹니다.
- **보상은 칭호·꾸미기·기록만.** 맛동산·장비·가챠는 건드리지 않습니다(사장님이 정하시기 전까지).
- **게임 계산은 서버가 합니다.** 폰은 입력을 보내고 화면을 그리기만 합니다. 그래서 치팅(점수 조작)도 막기 쉽습니다. 기존 캐릭터·무기 코드를 그대로 재사용합니다(화면 없이 서버에서 돌려 봤고, 4명 × 5조합 × 15분을 돌려도 오류가 없었습니다).

## 3. 서버는 어디에, 얼마에

- 지금 봇이 사는 곳(bot-hosting)은 **독일**입니다. 한국에서 왕복 약 0.23초라 실시간 전투에는 느립니다. 봇 메모리도 여유가 없습니다.
- 그래서 **레이드 전용 작은 서버를 따로** 둡니다.
  - 1순위: Vultr **서울** 서버, 월 **$5(약 6,700원)**.
  - 2순위: Fly.io **도쿄**, 월 약 $5~11. 서버 관리가 필요 없고 도메인을 안 사도 됩니다. 대신 서울보다 0.03초 정도 느립니다.
  - 어느 쪽이 나은지는 **사장님 폰으로 잰 숫자**로 정합니다(4번 항목).
- 월 예산 1~2만원 안에 들어옵니다. 도메인을 사게 되면(연 만원대로 알려져 있는데 가격은 확인 못 했습니다) 추가됩니다.
- 봇은 10분마다 스스로 재시작하지만, 레이드 서버는 봇과 분리되어 있어서 **봇이 재시작해도 진행 중인 판은 안 끊깁니다.**

## 4. 사장님이 하실 일

**지금 바로 (5분)**
1. 제가 "핑 시험 페이지" 링크를 드리면 폰에서 열고 "시작"을 누른 뒤 나온 숫자를 알려 주세요(Wi-Fi 한 번, 데이터 한 번).
2. `IPHONE_CHECKLIST.md` 를 아이폰으로 눌러 보고 결과를 알려 주세요. 특히 **홈 화면에 추가했을 때 디스코드 로그인이 되는지**가 제일 중요합니다.
3. **질문**: 처음에 "웹 팝업창"이라고 하신 화면이 정확히 뭔가요? 디스코드 안에서 링크를 눌렀을 때 뜨는 창인지, 사파리/크롬인지 스크린샷 한 장이면 됩니다. 디스코드 안의 창이면 설정 한 줄로 해결될 수도 있습니다.

**숫자가 좋게 나오면**
4. Vultr 가입(해외 결제 되는 카드) 후 "API 키"를 만들어 GitHub 저장소 비밀 금고(Settings → Secrets)에 `VULTR_API_KEY` 이름으로 넣어 주세요. **채팅에 붙여넣지 마세요.** 서버를 만드는 건 제가 합니다.
5. 도메인을 살지 정해 주세요(무료 방법을 먼저 시도해 보고 안 되면 구입).

**나중에**
6. 디스코드 모집 글을 올릴 채널 정하기, 대사 초안 읽고 OK/빼기, 시험 플레이를 같이 해 줄 클랜원 3~4명.
7. 보상(맛동산 등)을 연결할지 말지 결정.

가입·결제·디스코드 설정 말고는 서버 설정, 프로그램 설치, 코드, 배포 모두 제가 합니다.

## 5. 앞으로의 순서

| 단계 | 하는 일 | 크기 |
|---|---|---|
| 0 | 폰 지연 측정, 서버에서 게임 계산이 충분히 빠른지 측정, 아이폰 확인 → 서버 위치 결정 | 작음~중간 |
| 1 | 게임 코드를 "여러 명" 구조로 바꾸고(솔로가 깨지지 않는지 자동 시험으로 확인), 2~4명이 같이 움직이고 싸우는 최소 동작 | **큼** |
| 2 | 파티 방 만들기·초대 링크·준비·재접속·방장이 나갔을 때 | 중간 |
| 3 | 또뀨 레이드 완성(역할, 협동 기믹, 쓰러짐/일으키기, 자리 비움 보호) | 큼 |
| 4 | 칭호·기록 보드·보상 연결 | 중간 |
| 5 | 다른 보스, 주간 로테이션, 혼자서 AI 동료와 하는 연습 레이드 | 계속 |

"크기"는 에이전트 작업 횟수에 대한 제 어림짐작입니다. 1단계가 제일 큽니다. 서버에서 돌아간다는 것은 증명했지만, **다른 사람 캐릭터와 무기 이펙트를 내 화면에 그리는 일**은 아직 하나도 안 만들었고 이게 전체의 절반 이상입니다.

## 6. 솔직하게 모르는 것

- 서울 서버의 **실제 폰 지연**(아직 못 쟀습니다. 위 숫자는 "서울-독일 약 0.23초, 서울-도쿄 약 0.035초"라는 제3자 자료입니다).
- 아이폰 사파리/홈 화면 앱에서의 **로그인 복귀, 소리 복구, 백그라운드 후 연결**. 제 시험 환경에는 크롬만 있어서 못 봅니다. 그래서 확인표를 드립니다.
- 보스 체력 등 **밸런스 숫자**는 전부 초안입니다(캐릭터별 초당 피해량을 아직 안 쟀습니다).
- 서버 요금 중 도메인 가격, 해외 카드 수수료는 확인 못 했습니다.
- 안드로이드 앱 껍데기(스토어 앱)는 나중에 선택할 수 있는 항목으로만 남겨 두었습니다.

## 7. 레이드를 기다리지 않고 지금 솔로에 넣을 수 있는 것

- 홈 화면에 추가했을 때 주소창 없는 전체화면 + 앱 아이콘(지금은 흐접새우 아이콘이 비어 있습니다)
- 노치에 점수/버튼이 가려지는 것 고치기
- 손가락 두 개를 대면 조이스틱이 튀는 것 고치기
- 전화 뒤 소리가 죽는 것 복구, 판 도중 화면이 꺼지지 않게
- 판 저장 "이어하기"(별도 작업 진행 중)
- 타이틀 화면에 "홈 화면에 추가하세요" 안내

원하시면 이것들을 먼저 해서 클랜원에게 바로 체감시킬 수 있습니다.
