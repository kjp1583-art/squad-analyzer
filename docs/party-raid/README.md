# 흐접새우 4인 파티 레이드 — 사장님용 요약

(2026-10-08 개정 · 비판 검토 3건 반영 · **2차 개정: 사장님 답변(안드로이드, 디스코드 내부창) 반영** · 자세한 기술 내용은 `DESIGN.md`, 폰 확인표는 `IPHONE_CHECKLIST.md`(1부 안드로이드 · 2부 아이폰 지원자용), 아이폰 클랜원에게 보낼 글은 `FORWARD_TO_IPHONE_FRIEND.md`)

## 먼저, 8줄 요약

1. 솔로 게임이 "꺼지는" 건 웹 탓이 아니라 **판을 폰 메모리에만 들고 있어서**입니다. 새로고침하면 처음부터라는 건 제가 확인했습니다. 아이폰이 얼마나 자주 페이지를 버리는지는 **아직 모릅니다**(아이폰은 지원자가 있을 때만 확인합니다).
2. "웹 팝업창"의 정체는 **확인됐습니다**: 사장님 폰은 안드로이드이고, 그 창은 **디스코드 앱 안에서 게임 링크를 눌렀을 때 뜨는 내부창**입니다. 이 창은 다른 화면에 다녀오면 페이지를 지워서 게임이 첫 화면으로 돌아갑니다. 이전에 말씀드린 "아이폰 홈 화면 앱의 완료 막대 창" 추측은 **틀렸습니다(철회)**. 레이드 모집글도 디스코드에 올라가므로 **이 내부창이 레이드의 1순위 환경**입니다.
3. 레이드는 **서버가 게임 계산을 맡습니다.** 앱을 잠깐 나갔다 오거나 내부창이 지워져도 같은 링크로 다시 들어오면 같은 판에 붙습니다 — 단 **15초 안의 짧은 이탈만 보호**됩니다. 45초가 넘으면 쓰러진 걸로 처리되고, 서버가 죽거나 교체되면 진행 중인 판은 사라집니다.
4. 서버는 따로 둡니다. 1순위 Vultr **서울** 월 $5(약 6,700원), 2순위 Vultr **도쿄** 월 $5. **도메인 구입이 필수**입니다(연 만원대로 알려짐, 가격은 확인 못 함). Fly.io 는 이번 검토에서 **뺐습니다**.
5. 레이드 화면은 **레이드 서버가 직접 줍니다.** 솔로 게임을 하루에도 여러 번 고쳐도 레이드가 깨지지 않게 하려는 구조입니다. 대신 레이드 주소에서 **디스코드 로그인을 한 번 더** 하셔야 합니다.
6. 일정은 정정합니다. 이전에 말씀드린 "약 15세션"은 **틀렸습니다.** 다시 합산하니 **약 40~59세션**입니다. 그래서 중간에 사람이 해 볼 수 있는 **공동 호드 알파**와 **진행/중단 점검 3곳**을 넣었습니다.
7. 가장 큰 일은 "다른 사람 캐릭터와 이펙트를 내 화면에 그리는 일"입니다. 아직 손도 못 댔습니다. 보스 체력 등 밸런스 숫자는 전부 초안입니다.
8. 사장님이 이미 해 주신 것: **안드로이드라는 것, 팝업창이 디스코드 내부창이라는 것** — 스크린샷은 이제 필요 없습니다. 남은 것은 **선택**입니다: 안드로이드 확인표(`IPHONE_CHECKLIST.md` 1부, 약 15~20분)와, 클랜 디스코드에 폰 기종 투표 올리기, 아이폰 쓰는 클랜원 한 분께 부탁하기(`FORWARD_TO_IPHONE_FRIEND.md`의 글을 붙여 넣기). 사장님이 직접 아이폰 확인을 하실 필요는 없습니다.

## 1. 지금 겪으시는 문제

**확실한 것**
- 지금 솔로 게임은 하던 판을 폰 메모리에만 들고 있고 어디에도 저장하지 않습니다. 폰 크기 브라우저에서 20초 하다가 화면을 숨기고 새로고침하면 **타이틀 화면**으로 돌아가는 걸 제가 확인했습니다.
- 다만 이건 "새로고침하면 처음부터"라는 사실일 뿐입니다. **아이폰이 이 시간 안에 페이지를 실제로 버리는지는 못 봤습니다** → 아이폰 확인표(`IPHONE_CHECKLIST.md` 2부) 1번으로, 지원자가 있을 때만 확인합니다.

**확인된 것 — "웹 팝업창"은 디스코드 앱 안의 내부창** (사장님 답변)
- 사장님 폰은 **안드로이드**이고, 게임 링크를 디스코드 앱 안에서 누르면 뜨는 **내부(내장) 브라우저 창**이 "웹 팝업창"의 정체입니다. 그 창은 다른 화면에 다녀오면 페이지를 지워 버려서 게임이 첫 화면(키아트)으로 돌아갑니다. ("내부창이었던 것 같다"는 기억에 따른 답이라, 안드로이드 확인표 A1·A2 가 한 번 더 확인합니다.)
- 그래서 솔로가 처음으로 돌아가는 이유는 **"판을 폰 메모리에만 들고 있는데 디스코드 내부창이 페이지를 지워서"**입니다. 웹이라서 생기는 일이 아닙니다.
- 이전에 말씀드린 "아이폰 홈 화면 앱에 뜨는 완료 막대 창" 추측은 사장님 증상의 설명으로는 **틀린 추측이라 철회**했습니다. 아이폰 사용자에게 비슷한 문제가 있는지는 **아직 모르고**, 별개의 위험으로 남겨 둡니다(아이폰 지원자가 있을 때만 확인).
- 아직 모르는 것: 그 내부창이 어떤 종류인지(기종·디스코드 버전에 따라 다를 수 있음), **창이 지워져도 로그인·저장 공간이 남는지**, 디스코드 로그인(승인) 뒤 어디로 돌아오는지, 메뉴에 "브라우저로 열기"가 있는지 → 안드로이드 확인표가 묻는 것들입니다.

**해결 방향**
- 솔로: **"이어하기"(판 저장·복구)가 바로 이 경우를 겨냥합니다.** 별도 작업(#12)이 이미 하고 있고, 화면이 숨겨지는 순간에 판을 폰 저장 공간(`localStorage`)에 저장합니다. 다만 내부창이 저장 공간을 남겨 두는지는 아직 확인 못 해서(확인표 A6), 안 남는다면 저장 방식을 다시 봅니다.
- 레이드: 서버가 판을 들고 있어서 내부창이 지워져도 같은 링크를 다시 누르면 같은 판에 다시 붙습니다. 레이드는 **디스코드 로그인 확인 화면을 거치지 않고** 복귀하도록 만들고, 내부창 안의 디스코드 로그인(승인) 왕복·로그인 유지·"브라우저로 열기" 안내까지 1순위 환경으로 설계합니다.

## 2. 레이드는 이렇게 만듭니다 (한 장 요약)

- **솔로는 그대로.** 밀려오는 적을 베는 게임은 건드리지 않습니다. 레이드는 새로 추가하는 콘텐츠입니다.
- **4명이 실시간으로 같이 싸우는 보스전.** 첫 보스는 **또뀨의 진실의 방(재판 레이드)** 을 제안합니다. 한 판 12~13분. 이번에 **첫 버전을 줄였습니다**: 역할 버튼 2종(탱커·서포터), 협동 기믹 2종(흩어지기, 감옥에 갇힌 동료 구하기). 나머지는 사람이 해 본 뒤에 추가합니다. 정원은 **2~4명 가변**(4명이 못 모여도 열 수 있게).
- **조작은 솔로처럼 한 손.** 무기는 자동으로 나가고, 손가락은 이동 + 역할 버튼 1개. 캐릭터 17명 모두 역할이 정해져 있고, **해금과 상관없이 전원 선택 가능**으로 바꿨습니다(해금을 서버가 검증할 방법이 없고, 능력치를 똑같이 맞추기 때문).
- **협동은 "움직이기"만으로 됩니다.** 구출할 때는 서버가 사람마다 기둥을 정해 주고 화면에 "네 기둥은 ②"라고 화살표로 알려 줍니다.
- **보상은 칭호·꾸미기·기록만.** 맛동산·장비·가챠는 건드리지 않습니다. 단 칭호를 저장하려면 브장신 기록 파일에 칸을 추가해야 해서, 그것도 **사장님 승인이 필요한 항목**입니다.
- **게임 계산은 서버가 합니다.** 기존 캐릭터·무기 코드를 서버에서 그대로 돌려 봤고(4명 × 5조합 × 15분, 오류 없음), 다만 **아직 "누구 무기인지" 구분이 없어 동작의 의미는 틀린 상태**입니다. 그걸 고치는 게 1단계 일입니다.

## 4. 서버는 어디에, 얼마에

- 지금 봇이 사는 곳(bot-hosting)은 **독일**입니다. 한국에서 왕복 약 0.23초라 실시간 전투에는 느립니다(제3자 자료, 폰 실측 아님). 봇 메모리도 여유가 없습니다.
- 그래서 **레이드 전용 작은 서버를 따로** 둡니다. 서버가 레이드 화면 파일도 함께 내려 줍니다.
  - 1순위: Vultr **서울**, 월 **$5(약 6,700원)**.
  - 2순위: Vultr **도쿄**, 월 $5(같음). 서울이 느리거나 재고가 없을 때.
  - ~~Fly.io 도쿄~~: 공식 문서를 확인하니 싼 사양은 CPU를 6.25%만 보장해 레이드 중 멈추고, 멈추지 않는 사양은 월 약 $33~43이라 예산을 넘습니다.
  - 어느 쪽이 나은지는 **사장님 폰으로 잰 숫자**로 정합니다.
- **도메인은 필수**입니다(서버 주소·디스코드 로그인 복귀 주소가 고정이어야 해서). 연 만원대로 알려져 있지만 **가격은 확인 못 했습니다.**
- 월 합계: **$5 + 도메인**. 방이 늘어 서버를 키우면 $15(약 20,000원)까지. 예산 1~2만원 안입니다. 해외 카드 수수료는 확인 못 했습니다. Vultr 는 **서버를 꺼 두기만 해도 과금**되고(삭제해야 멈춤), 한 달 최대 672시간 기준입니다.
- 봇은 10분마다 **확인해서 코드가 바뀌었을 때만** 재시작합니다(이전 요약의 "10분마다 재시작"은 부정확했습니다). 레이드 서버는 봇과 분리되어 있어서 봇이 재시작해도 진행 중인 판은 안 끊깁니다.

## 7. 앞으로의 순서와 크기 (정정)

## 8. 솔직하게 모르는 것

- 폰이 앱을 나갔을 때 **연결을 몇 초 만에 끊는지**(안드로이드 디스코드 내부창·아이폰 모두 실기기 측정 전 모름), 아이폰이 페이지를 얼마나 자주 버리는지.
- 디스코드 내부창이 **어떤 종류인지**, 지워져도 **로그인·저장 공간이 남는지**, 화면이 숨겨질 때 저장하는 이벤트를 주는지(이어하기 시험판으로 확인).
- **클랜원 중 아이폰 비율**(조사 안 함, 투표 제안)과 **아이폰에서 같은 문제가 있는지**(지원자가 없으면 미검증).
- 서울 서버의 **실제 폰 지연**(위 숫자는 "서울-독일 약 0.23초, 서울-도쿄 약 0.035초"라는 제3자 자료).
- 홈 화면 앱·디스코드 안 창(안드로이드 내부창 포함)에서의 **로그인 복귀, 소리 복구**(제 시험 환경에는 크롬 에뮬레이터만 있음).
- **클랜원이 4명 모이는지**. 공개 순위표(읽기 전용) 한 번 조회에서 상위 20줄이 가득 찼지만 그보다 더 있는지(상한)는 모릅니다. 0단계에서 최근 14일 활동 인원을 집계합니다.
- 보스 체력 등 **밸런스 숫자**는 전부 초안이고, 봇 시뮬레이션이 "재미있다"는 뜻은 아닙니다(사람 시험으로 판정).
- 4명 화면을 폰에서 그릴 때의 **성능·발열**.
- 도메인 가격, 해외 카드 수수료.
- 안드로이드 앱 껍데기(스토어 앱)는 나중에 선택할 수 있는 항목으로만 남겨 두었습니다.

## 9. 레이드를 기다리지 않고 지금 솔로에 넣을 수 있는 것

순서를 정했습니다. 원하시면 이 순서대로 먼저 하겠습니다. 이번에 확인된 사실(디스코드 내부창이 페이지를 지움) 때문에 **1순위가 바뀌었습니다.**
- **1순위 — 판 저장 "이어하기"**(별도 작업 #12 진행 중). 사장님 증상을 직접 겨냥합니다. 내부창이 저장 공간을 남기는지는 안드로이드 확인표 A6 으로 확인합니다.
- **바로 가능(폰 종류 확인 없이)**: 손가락 두 개를 대면 조이스틱이 튀는 것 고치기, 전화 뒤 소리가 죽는 것 복구, 판 도중 화면이 꺼지지 않게.
- **디스코드 안 "화면이 자꾸 초기화되나요?" 안내**: 내부창의 "브라우저로 열기" 메뉴 이름을 알아야 쓸 수 있어서 안드로이드 확인표 A4 뒤에 합니다.
- **아이폰 지원자가 있으면 한 번 보고**: 노치에 점수/버튼이 가려지는 것 고치기.
- **미룬 것 — 홈 화면에 추가했을 때 주소창 없는 전체화면 + 앱 아이콘, "홈 화면에 추가하세요" 안내.** 미루는 이유가 바뀌었습니다. 이전에는 "아이폰 완료 막대 창 때문에 증상이 늘 수 있어서"였지만 그 추측은 철회했습니다. 지금 이유는 ① 클랜원 대부분이 디스코드 내부창으로 들어와서 효과가 일부에게만 닿고, ② 아이폰에서 별도 창이 뜨는 위험은 아직 확인 못 해서(아이폰 지원자가 있을 때만 확인)입니다. 그래서 **우선순위를 낮췄고**, 아이폰 확인(표 2부 4·5번) 뒤에 합니다. 지원자가 없으면 하지 않습니다.
- **게임 시작 때의 자동 로그인 이동 줄이기**: 이제 "가설이 맞으면"이 아니라, 안드로이드 확인표 A5(내부창에서 로그인 왕복)에서 문제가 보일 때 합니다.
