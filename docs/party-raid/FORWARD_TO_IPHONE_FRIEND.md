# 아이폰 쓰는 클랜원께 보낼 부탁 글 (디스코드에 4개 글로 나눠 올리기)

> **⛔ 폐기 (2026-10-09, 사장님 결정: 레이드는 PC 전용).** 아이폰 지원자에게 부탁하지 않습니다. 이 글은 보내지 마세요. 기록으로만 남깁니다.

**사장님께 — 이렇게 하시면 됩니다**
- 아래 **회색 상자(코드 상자) 4개를 순서대로** 디스코드 채널에 올리세요. 상자마다 하나의 글이고, 모두 디스코드 한 글의 글자 수 한도(2000자) 안입니다. 각 상자 오른쪽 위의 복사 버튼을 누르면 상자 안의 글만 복사됩니다. 첫 상자가 부탁 글이고, 나머지 3개가 질문 목록입니다. 디스코드는 표를 그리지 못해서 질문을 번호 붙은 글로 풀어 썼습니다.
- 사장님은 안드로이드라 아이폰 확인은 아이폰을 쓰는 클랜원이 해 주셔야 합니다. 한 분이면 충분하고, 아무도 없으면 아이폰은 "미검증"으로 두고 안드로이드부터 갑니다.
- 첫 글에는 **원본 표 링크**가 있습니다. 저장소(`kjp1583-art/squad-analyzer`)가 공개인 것을 확인했습니다(2026-10-08). 링크는 브랜치 이름이 아니라 **커밋 번호로 고정**해 두어서, 브랜치를 병합하거나 지워도 열립니다. 대신 표를 고치면 링크의 커밋 번호도 바꿔야 합니다(저에게 말씀하세요).
- 답을 받으면 그대로 저에게 붙여 주세요(번호와 고른 것만 와도 됩니다).
- 누구에게 보낼지는 정하지 않았습니다. 클랜 전체 채널에 올릴지, 한 분께 개인 메시지(DM)로 보낼지 사장님이 정하세요. 질문 2a·2c 는 디스코드 안에서 게임 주소를 눌러야 해서, 지원자가 자기 개인 메시지에서 해도 됩니다.
- 질문 내용의 원본은 `PHONE_CHECKLIST.md` 2부입니다. 표를 고치면 아래 글도 같이 고칩니다(구현하는 쪽 메모).

## 첫 번째 글 — 부탁 (654자)

```text
아이폰 쓰는 분, 부탁 하나만 들어주실 수 있나요? 🙏
제가 만드는 흐접새우 4인 협동 레이드가 **아이폰에서 어떻게 보이는지 확인할 방법이 없어서요.** (제 폰은 안드로이드예요) 한 분만 해 주셔도 큰 도움이 돼요.
**하실 일**: 아이폰으로 게임을 열고, 판 하다가 홈으로 나갔다 오기 같은 것을 아래 번호대로 눌러 보고 **보이는 것만** 알려 주세요.
**게임 주소**: <https://kjp1583-art.github.io/squad-analyzer/survivors.html>
**시간**: 20~30분이에요. 나눠서 해도 되고, 맨 앞의 1번과 2a~2c 만 해 주셔도 큰 도움이 돼요.
**답하는 법**: 번호와 고른 칸만 적어 주세요. 예: "1 ②". 이상하면 한 줄 설명이나 스크린샷이요.
**참고**: 도중에 디스코드 로그인(승인) 화면이 한 번 나올 수 있어요. 그것도 어떻게 되는지 알려 주세요.
질문 목록은 바로 아래 글 3개예요. 표로 보고 싶으면 <https://github.com/kjp1583-art/squad-analyzer/blob/358d3513df5786f6decb706f0ad14bcd3c9dc8fc/docs/party-raid/PHONE_CHECKLIST.md> 를 열어 "2부 — 아이폰" 부분만 보세요. 감사합니다!
```

## 선택 사항 — 클랜 전체에 올리는 폰 기종 투표 (아이폰 비율을 알아보려고)

전체 클랜원에게 올리실 거면 쓰세요. 아이폰 비율을 모르기 때문입니다. **올린 뒤 🤖 와 🍎 이모지 반응을 사장님이 하나씩 먼저 눌러 두세요.** 먼저 달아 두지 않으면 선택지가 안 보여서 클랜원이 이모지를 직접 찾아야 합니다.

```text
🤖 안드로이드(갤럭시 등)　 🍎 아이폰
```
