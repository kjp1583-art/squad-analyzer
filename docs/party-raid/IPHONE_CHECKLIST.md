# 아이폰 확인표 (5분)

사장님이 아이폰으로 눌러 보고 "된다 / 안 된다 / 이상하다" 한 줄씩만 알려 주시면 됩니다. 사진이 있으면 더 좋습니다.
제 시험 환경에는 아이폰 사파리가 없어서, 이 항목은 사장님만 확인할 수 있습니다.

준비: 아이폰 사파리에서 흐접새우(`survivors.html`) 주소를 열어 둡니다. 디스코드에 로그인되어 있는 상태가 좋습니다.

| # | 눌러 볼 것 | 알려 주실 것 |
|---|---|---|
| 1 | 흐접새우를 하다가 **홈 버튼**을 눌러 다른 앱을 30초 보고 돌아오세요 | 게임이 멈춘 채 그대로인가요? 아니면 처음 화면(키아트)으로 돌아가 있나요? |
| 2 | **디스코드 앱 안에서** 게임 링크를 눌러 열고(처음에 말씀하신 "팝업창"이 이거 맞나요?), 하다가 디스코드의 다른 채널을 갔다 오세요 | 게임이 남아 있나요? 팝업창이 이 화면 맞나요(스크린샷)? |
| 3 | 사파리 아래 **공유 버튼 → "홈 화면에 추가"** | 맨 위에 "웹 앱으로 열기" 스위치가 보이나요? 추가된 아이콘은 그림이 나오나요, 빈 칸/글자만 나오나요? |
| 4 | 새로 생긴 **홈 화면 아이콘으로** 게임을 여세요 | 주소창 없이 전체화면인가요? 위쪽 시계/노치 밑에 점수나 버튼이 가려지나요? 아래쪽 게임 화면이 잘리거나 아래 막대에 걸리나요? |
| 5 | **홈 화면 앱에서** 디스코드 로그인(승인)을 끝까지 하세요 (**가장 중요**) | 끝나고 어디로 돌아오나요(게임 안 / 아래쪽 "완료" 창 / 사파리)? 돌아온 뒤 로그인 상태인가요? |
| 6 | **소리**: 무음 스위치를 켠 채 한 번, 끈 채 한 번 해 보세요. 게임 중에 전화나 알림이 오게 한 뒤에도 | 배경음/효과음이 나나요? 전화·알림 뒤에도 계속 나나요? |
| 7 | **손가락 두 개**로 동시에 누르거나 화면 가장자리에서 쓸어 보세요. 아래로 당겨도 보세요 | 조이스틱이 튀나요? 뒤로가기가 되나요? 화면이 확대되거나 새로고침되나요? |
| 8 | 폰을 **가로로** 돌려 보세요 | 위쪽 정보가 노치에 가려지나요? 화면이 찌그러지나요? |
| 9 | 화면을 **껐다 켜거나 5분쯤** 두었다가 돌아오세요 | 소리와 화면이 정상인가요? 게임은 어떤 상태인가요? |
| 10 | **저전력 모드**를 켜고 해 보세요 | 많이 버벅이나요? |

참고
- 진동은 아이폰에서 원래 안 됩니다. 확인하지 않으셔도 됩니다.
- 이미 흐접새우를 홈 화면에 추가해 쓰고 계셨다면 그 상태에서 3·4·5번을 먼저 눌러 보세요. 최근 아이폰(iOS 26)은 홈 화면에 추가한 사이트를 기본으로 앱처럼 열기 때문에, 로그인이 이미 불편했을 수 있습니다.
- 아이폰 기종과 iOS 버전(설정 → 일반 → 정보)도 한 줄 알려 주세요.
- 이 표는 나중에 레이드가 만들어지면 한 번 더 드립니다(전투 중 앱 나갔다 오기, 연결 끊겼다 복귀 등).
