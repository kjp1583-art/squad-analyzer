# 아이폰 확인표 (개정판 — 1차 20~30분, 나눠서 하셔도 됩니다)

한 칸에 질문 하나입니다. **괄호 안의 고르기 중 하나만 적어 주시면** 됩니다(예: "1 ②"). 이상하면 "이상함 + 한 줄", 가능하면 **스크린샷**.
제 시험 환경에는 아이폰 사파리가 없어서 이 표는 사장님만 확인할 수 있습니다. 안드로이드는 맨 아래 별도 표입니다.

**열어 볼 주소**: 흐접새우 `https://kjp1583-art.github.io/squad-analyzer/survivors.html` (주소가 다르면 알려 주세요)
**시간 계산**: 1차 전체 약 20~30분(30초·5분 기다리는 칸, 무음 스위치 두 번, 아이콘 추가 포함). 한 번에 못 끝내면 번호 단위로 나눠서 해도 됩니다.
**1차 / 2차 / 3차**: 1차는 지금 있는 게임으로 바로 됩니다. 2차는 제가 시험 페이지를 만든 뒤 링크를 드립니다. 3차는 레이드가 만들어진 뒤입니다.

## 1차 — 지금 바로

### 준비 (먼저 세 줄만)
| # | 확인 | 고르세요 |
|---|---|---|
| A | 기종과 iOS 버전 (설정 → 일반 → 정보) | 적어 주세요 (예: 아이폰 14, iOS 18.3) |
| B | 사파리에서 `discord.com` 을 열면 **로그인이 되어 있나요?** (디스코드 앱 로그인과는 별개입니다) | ① 되어 있다 ② 아니다(로그인 입력 화면) ③ 모르겠다 |
| C | 흐접새우를 **이미 홈 화면에 추가해 쓰고 계셨나요?** | ① 예 ② 아니오 |

### 본 확인
| # | 해 볼 것 | 고르세요 |
|---|---|---|

| 4b | 4a 의 창(또는 앱)에서 판을 시작해 20초 했을 때 | ① 정상 ② 이상함(한 줄) |

| 7b | 화면 **왼쪽 가장자리에서 쓸어** 보세요 | ① 뒤로가기가 된다 ② 아무 일 없다 |

| 9b | 같은 것을 **60초** | ① 그대로 ② 처음 화면 |

|---|---|---|

| 14 | **대기방 시험**: 방에 들어가 **손 안 대고 2분** 두기 | 화면이 꺼졌나요 / 돌아왔을 때 방에 남아 있나요 |

## 3차 — 레이드가 만들어진 뒤
- 디스코드 모집글 링크 → 로그인 → 방 입장 → 홈 화면으로 나갔다 → 돌아오기.
- **15분 레이드 장면 뒤** 기기 발열, 배터리 감소량, 버벅임.
- 전투 중 앱 나갔다 오기(15초·45초), 연결 끊겼다 복귀.

참고
- 진동은 아이폰에서 원래 안 됩니다. 확인하지 않으셔도 됩니다.
- **이미 흐접새우를 홈 화면에 추가해 쓰고 계셨다면(준비 C ①)** 그 상태에서 4a~5 를 먼저 눌러 보세요. 최근 아이폰(iOS 26)은 홈 화면에 추가한 사이트를 기본으로 앱처럼 열기 때문에, 로그인이 이미 불편했을 수 있습니다.
- 이 표의 1차 결과는 "지금 있는 게임" 기준입니다. 지금 게임에는 아이콘·전체화면 설정이 없어서, 3·4번은 **이미 홈 화면에 추가해 쓰던 클랜원이 겪고 있을 상태**를 기록하는 용도입니다. 앞으로 만들 앱(레이드)의 동작은 2차에서 따로 확인합니다.
- 결과에 따라 달라지는 것: 4a 가 "있다"이면 "웹 팝업창" 가설이 맞는 것이고 홈 화면 앱화는 미룹니다. 5 가 ③·④·⑤ 이면 레이드 로그인 방식(중계 로그인)을 바꿉니다. 11 의 값이 레이드의 자리비움 시간(15초·45초)을 정합니다.
