## 분석기
🌱 밴픽 화면에서 클랜 가입 7일 이내인 새 클랜원 이름 앞에 새싹이 붙어요. 오래된 내전 기록이 있는 돌아온 고참과 외부 스크림 상대에겐 붙지 않아요.

## 웹
📰 웹 메인 맨 위에 주간 신문 「주간스쿼드」가 생겼어요. 매주 월요일 아침 AI 선생님이 지난주 내전·칼바람·레이드를 기사와 칼럼으로 정리해요.
💬 주간스쿼드 지면 아래에 디스코드 로그인으로 댓글을 달 수 있고, 독자 반응은 다음 호 기사에 반영돼요. 지난 호도 다시 볼 수 있어요.
🤝 새 「스크림」 탭에서 외부 클랜별 상대전적(승패·승률·최근 경기)과 경기 기록, 스크림 공지 기록을 볼 수 있어요.
🏆 웹 프로필에 브장신 멸망전 우승 뱃지가 표시돼요.
🧸 브키도감에 인형·트로피 사용 안내와 열쇠 효과 설명을 새로 넣었어요.

## 봇
🧸 브장신 인형은 사용하면 30포인트, 미니 트로피는 5포인트를 줘요.
🏆 멸망전 우승 1회마다 전투 능력치가 조금씩 올라가요(최대 10회분, 성장 속도는 그대로예요).
🐲 레이드 현황에 참가자별 공격 횟수(쓴 횟수/최대)가 표시돼요.
📅 `현황`을 치면 오늘 쓰다듬기·모의 내전·이야기·아카보시·퀴즈·출근·레이드를 다 했는지 체크리스트로 보여줘요.
🌟 전투 중에 스킨이 잠깐 벗겨져 보이던 문제를 고쳤어요.
🐲 시간이 지난 밴픽 버튼을 누르면 지난 판 결과를 이번 판 결과처럼 보여 주던 안내를 바로잡았어요.
🩹 누락경기 채널에 주소를 올리면 이제 봇이 항상 답해요. 이미 처리한 주소도 상태를 알려 주고, 경기가 아직 안 올라온 판은 20분 뒤 다시 시도해요.
🤝 스크림 공지에서 상대 클랜 이름을 더 정확하게 읽어요.
