# RESULT — 동료 개편 (브랜치 rs-crew · 웹 squad-analyzer + 봇 squad-naejeon-bot)

## 한 일
**서버 (bot.py `BRJ2:SUMMON` 구역 · 새 표/함수 위주, 기존 줄은 `_bs_party_mult`·`_bs_view`·`_bs_summon` 결과 한 줄·`_bt_parts` 몇 줄)**
- **직업군(포지션)** — 주 포지션 → 직업군: 탑=탱커 · 정글=암살자 · 미드=마법사 · 원딜=사수 · 서폿=치유사(`BRS_FAMS`·`BRS_POS_ROLE`). 포지션 정보(카드 사실 「주 포지션 X」)가 없으면 카드 id 로 한 직업군에 고정(`_bs_role_idx` — 사람마다 늘 같다).
- 직업군별 **고유 액티브 1 + 고유 패시브 1** (`_bs_skills`): 이름 앞에 등급 말머리, 위력은 등급 × 동료 레벨.
  - 탑: 방패 도발(받는 피해 −% + 주변 몬스터 도발 타격) / 패시브 방어력
  - 정글: 급습(달려가 연타) / 패시브 공격력
  - 미드: 마력 폭발(범위 2연타) / 패시브 크리티컬 피해
  - 원딜: 집중 사격(한 마리에 5발) / 패시브 크리티컬 확률
  - 서폿: 응급 처치(체력 회복 + 보호막) / 패시브 체력
  - 패시브는 파티에 있으면 병아리 스탯이 오른다 → `_bs_passive_bonus` → `_bt_parts`(전투력). 상한 `BRS_PAS_CAP`.
- **5인 장착** — `BRS_PARTY_MAX = 5`. 4·5번째 칸은 장착효과 절반(`BRS_SLOT_W`).
- **시너지 세트** (`_bs_synergy`·`BRS_SYN_*`): 같은 직업군 2·3·4·5명 · 같은 등급 2·3·4·5명 · 올라운더(5포지션 한 명씩) · 콤보(수호 콤비=탑+서폿 / 딜러 라인=미드+원딜 / 선봉대=탑+정글). 같은 계열은 가장 높은 단계 하나만. 합계 상한 `BRS_SYN_CAP`. 전투력(`_bt_parts`)에 반영, 뷰에 `syn`(발동 중)·`syn_table`(전체 목록).
- 뷰: 카드마다 `sk`(포지션·직업군·액티브·패시브), `pas`·`syn`·`syn_table`. 소환 결과에 `fam`.
- **균형 재조정(중요)**: 환생 속도 시험(`brj_pacing_test` 「스킬 상한 공짜」)이 아주 아슬아슬해서(원래도 28일에 스테이지 29/30), 5칸·패시브·시너지가 더해지면 환생이 8회로 튀었다. 그래서 **동료 1칸 장착효과를 낮췄다**(`BRS_GRADE_BONUS` 레전드 15%→7%, 유니크 9%→4%, 에픽 5%→2.25%, 레어 2.5%→1.15%, 노말 1%→0.5%). 최상위 5인 파티는 예전 3인 파티와 비슷하고 환생은 3회(≤4)로 통과.

**웹**

- `brjhunt.html` — 동료 창: 카드에 SD·포지션/직업군·⚡액티브·🔰패시브 · 파티 칸 5개 · 「파티 고유 스킬」 목록 + 패시브 합계 · **「🔗 시너지 세트 효과」(발동 중 + 합계 + 전체 목록)** · 소환 결과에도 그림.

## 남은 위험 / 결정 필요
- **결정 필요 — 장착효과 하향**: 위 균형 재조정으로 기존 유저의 칸당 공격·체력 보너스가 약 절반이 된다(대신 칸이 5개·패시브·시너지가 생김). 3장만 가진 유저는 순수하게 약해진다. 되돌리려면 `BRS_GRADE_BONUS` 를 올리되 `brj_pacing_test`(환생 속도)를 다시 돌려라. 환생 속도 기준 자체를 바꾸는 건 사장님 결정.
