# P-5 🖼 롤 프로필 아이콘 · 롤 레벨 표시
- 상태: 승인(2026-09-28 사장님 "p-5로 진행하고, 과거티어뱃지는 하지말자") · P-1~P-3·브키도감 뒤 착수
- 한 줄: 웹 프로필 이름 옆에 그 사람의 롤 프로필 아이콘과 롤 레벨(아이콘 아래 숫자)을 띄워요. 랭킹·게임 상세 이름 옆에도 작은 아이콘.
- 누구를 위해: 웹을 여는 클랜원 전원(최근 30일 협곡 190명). 다른 전적 사이트에서 익숙한 모양.
- 왜 지금: 사장님 요청(2026-09-28, 타 전적 사이트 스크린샷). 재료가 이미 있음 — 분석기 호스트가 Riot 키로 솔랭을 주기적으로 받는다(`fetch_solo_rank_by_riotid`).
- 무엇을:
  1. 분석기 호스트: 솔랭 받는 김에 account-v1 로 얻은 PUUID 로 summoner-v4 `by-puuid` → `profileIconId`·`summonerLevel` 를 받아 시트에 적는다(솔랭과 같은 탭의 새 열 또는 전용 탭). 호출 한도·429 지킴, 실패는 이전 값 유지.
  2. 웹: 프로필 헤더에 Data Dragon `img/profileicon/{id}.png`(최신 버전) + 레벨 뱃지. 없으면 기본 그림. 랭킹·게임 상세 10명에 작은 아이콘(지연 로딩).
- 하지 않음: 시즌별 과거 티어 뱃지(사장님 "하지말자").
- 만드는 순서: 1) 분석기 수집·시트 기록(릴리스) 2) 웹 프로필 헤더 3) 목록·게임 상세 작은 아이콘
- 위험·되돌리기: Riot 호출 증가(사람 수만큼 1회 추가) — 솔랭 주기와 같게. 웹은 값 없으면 기존 모양 그대로.
- 성공 지표: 2주 뒤 활성 클랜원 중 아이콘이 채워진 비율(목표 90%↑).
