# P-23 📱 프로필을 탭으로 — 전적까지 10화면을 1.5화면으로
- 상태: 제안 (10/11 기획 회의 차점권 20점 — 다수 효용 7 · 쉬움 6 · 사장님 방향 7)
- 한 줄: 폰으로 프로필을 열면 **전적 목록이 댓글 밑, 10화면 아래**에 있어요. 프로필을 [요약·전적·챔피언·분석·한마디] 탭으로 나누고 전적은 20판씩 보여 줘요. 데이터·계산은 그대로, 배치만 바뀝니다.
- 누구를 위해: 프로필을 여는 모든 사람 — 협곡 30일 활동 129명(통산 판수 중앙값 103판 · 100판↑ 65명), 봇의 '→ 내 프로필에서 보기'(`#p/`) 링크로 들어오는 사람 포함. 체감은 폰이 가장 크고 PC 도 전적이 3화면 아래.
- 왜 지금(10/11 기획 회의 Playwright 실측 · 360×780 · 실제 시트 · 통산 30~593판 7명 · 코드로 일부 직접 확인):
  - '전적' 머리글이 **6,579~8,440px = 8.4~10.8화면 아래**. 폰은 2단이 1단으로 접히며 왼쪽 열(모스트·추천 픽·닉 이력·내부티어 기록·GPTI·포지션·💬 댓글)이 통째로 먼저 쌓여 전적 앞에 카드 11~12개. 머리 카드 하나가 2,045~2,140px(칸 19~20개), 승률 링은 그 맨 아래.
  - **전적 목록에 한도가 없다**(직접 확인: `index.html` `matchHtml=list.map(r=>matchCard(...)).join("")` — 내전기록 탭엔 `LOG_LIMIT` 60 + 더보기가 있는데 프로필엔 없음). 통산 기준으로 열리는 `#p/` 공유 링크는 99판 34.9화면 · 252판 69.7화면 · **593판이면 137화면**(전적 카드 593장·img 11,595개·DOM 37,365개, CPU 4배 느리게 했을 때 그리는 데만 1.6초).
  - 댓글(💬)은 전적보다 앞에 있는데 시트 COMMENTS 에 프로필 댓글은 최근 30일 1건.
  - 같은 방향 선례: 업적 도감·장인랭킹 하위 탭(A-12 · 9/29)·미토 접기(A-17 · 10/10)는 **프로필 본문을 다루지 않았고** 프로필은 순찰에서 잰 적이 없다.
- 무엇을:
  1. 폰(≤820px) 프로필 머리 카드 바로 밑에 탭 줄: **[요약][전적][챔피언][분석][한마디]**.
  2. 요약: 승률 링을 맨 위로 + 핵심 6칸(내전 활약·KDA·AI점수·MVP율·솔랭·전투력) + '칸 더 보기'(나머지) + 최근 5판 줄.
  3. 전적: **20판씩 + '20판 더'**(PC 에도 같이 적용 — 한도 없는 렌더 해소). 챔피언 상세 '사용된 게임'(리 신은 폰에서 69화면)도 20개씩.
  4. 챔피언: 모스트·추천 픽·포지션 / 분석: 내 기록실·성장 그래프·AI 주간평·GPTI·내부티어 기록·견제 지수 / 한마디: 댓글.
  5. 주소는 `#p/닉` 뒤에 탭을 붙이는 방식이라 공유·봇 링크가 그대로 열린다. PC 는 2단 유지, 전적만 20판씩.
  - **사장님이 고르실 것**: 첫 탭을 '요약' 으로 할지 '전적' 으로 할지.
- 이미 있는 것과의 관계: 내전기록 `LOG_LIMIT`(같은 더보기 방식 재사용) · A-12·A-17(다른 탭 정리) · P-19(모든 탭 공통 머리 영역 — 서로 겹치지 않음). P-3 라인 카드·P-1 기록실·P-14 판 순서 칸이 프로필에 계속 쌓이는 문제의 구조적 해법.
- 시제품: 위 구성. 승인되면 `lab/P-23.html` 에 실제 시트로 도는 폰 프로필 미리보기를 먼저. 시험은 `tests/web_mito_phone_test.py` 틀로 '전적 시작 위치 1.5화면 이내 · 가로 넘침 0 · 칸 목록 대조(빠진 칸 0)'.
- 만드는 순서: 1) 전적 20판씩 + 더보기(PC·폰 공통 · S — 사실상 버그 수정이라 A 로 먼저 가능) 2) 폰 탭 줄 + 카드 재배치(M) 3) 챔피언 상세 '사용된 게임' 20개씩(S) 4) 2주 뒤 재측정.
- 위험·되돌리기: 익숙한 스크롤 동선이 바뀐다 → 탭 이름에 카드 이름을 그대로, 첫 출시는 폰만. `renderPlayer` 가 길어(~650줄) 카드를 옮기다 칸이 빠질 수 있다 → 출시 전 칸 목록 대조 시험. 데이터·계산 불변, 폰 전용 CSS + 탭 상태 하나라 원복 쉬움.
- 성공 지표: 폰 프로필의 '전적' 시작 위치(지금 6,500~8,400px → 목표 1,200px 이하) · 통산 프로필(`#p/`) 렌더 시간 · 디스코드 반응.
