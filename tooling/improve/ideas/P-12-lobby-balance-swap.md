# P-12 ⚖️ 기운 판은 시작 전에 — 대기실 '전력 차' 한 줄 + 1:1 맞바꾸기 제안
- 상태: 제안
- 한 줄: 내전 대기실에 10명이 다 들어오면 분석기가 "양 팀 예상 승률 41 : 59 — 기울었어요" 를 한 줄 띄우고, 크게 기울었으면 **딱 한 쌍**의 맞바꾸기(예: "A ↔ B 바꾸면 49 : 51")를 제안해요. 바꿀지는 방장이 정해요.
- 누구를 위해: 협곡 내전을 뛰는 클랜원 전원(최근 30일 286판) · 특히 팀을 손으로 짜는 방장.
- 왜 지금(2026-10-03 시트 CLASSIC_NORMAL 1,853판으로 다시 계산):
  - 양 팀 '평소 내전 승률'(그 판 이전 기록만, 10판↑ 선수만 있는 판 925판) 평균 차가 **4%p 이상인 판이 28%(262판)**. 그런 판은 강한 쪽이 **61.5%** 이겼고, **최근 30일은 60판 중 66.7%**.
  - 4%p 미만 판까지 합치면 강한 쪽 승률 54.3% — 기운 판이 결과를 끌고 간다.
  - 블루 승률 53.4%(진영 편차는 작음 — 이 기획의 대상 아님).
  - 웹 통계(`index.html` '우세팀 승률·팽팽한 판 비율')는 **지나간 판**을 보여 줄 뿐이고, 분석기 '게임 시작 화면' 예상 승률은 **로딩 화면이라 이미 못 바꾸는 시점**이다.
  - (근거 한계: 산식은 웹·분석기와 같은 '전투력'(내부티어+수축 승률)을 쓸 예정 — 위 숫자는 승률만으로 낸 근사치다.)
- 무엇을:
  1. **대기실 한 줄**(분석기 · 사용자 정의 게임 대기실에 10명이 찼을 때 1회, 사람이 바뀌면 다시)
     - "⚖️ 예상 승률 블루 44% : 레드 56% · 전력차 1.5" — 차이가 1 이하면 "팽팽해요 👍" 만.
     - 계산은 분석기 기존 `_team_split`/게임 시작 화면과 **같은 전투력 산식**(새 산식 없음).
  2. **1:1 맞바꾸기 제안**(전력차가 1.5 이상일 때만)
     - 25쌍(블루 5 × 레드 5) 중 차이를 가장 많이 줄이고 **같은 주포지션끼리**인 한 쌍을 우선. "🔄 A(블루·정글) ↔ B(레드·정글) 바꾸면 50 : 50".
     - 버튼 없이 안내만 — 실제 이동은 방장이 롤 대기실에서. 무시해도 아무 일 없다.
  3. **(선택) 대기실 채팅 한 줄** — 분석기 로비 소개처럼 방장 PC 한 대만 1회. 사장님이 원하실 때만 켠다.
  4. 결과 리포트에 "시작 전 예상 44:56 → 레드 승" 한 줄을 붙여 맞았는지 쌓아 간다(이미 있는 예상 승률 재사용).
- 이미 있는 것과의 관계:
  - 분석기 `⚖ 5:5 팀짜기`(8/16): 10명을 **처음부터 다시** 나눈다 — 이미 짠 팀을 거의 그대로 두고 싶을 때는 과하다. P-12 는 **한 쌍만** 바꾸는 가벼운 보정.
  - 게임 시작 화면 예상 승률: 같은 숫자를 **더 이른 시점**(대기실)에 보여 준다.
  - 웹 '팽팽한 판 비율': 출시 뒤 효과를 재는 지표로 그대로 쓴다.
  - 봇 `balance_lobbies`(조편성, 지금 출석판 꺼짐)와는 별개 — 분석기만 바꾼다.
- 시제품: 문구 예시
  ```
  ⚖️ 예상 승률  블루 41% : 레드 59%  (전력차 2.2 · 기울었어요)
  🔄 이렇게 바꾸면 → 수화은연(블루·원딜) ↔ RayB(레드·원딜)  =  49% : 51%
  -# 방장이 원할 때만 바꾸세요 · 같은 산식: 게임 시작 화면 예상 승률
  ```
- 만드는 순서: 1) 분석기 대기실 한 줄(전투력 재사용) 2) 1:1 맞바꾸기 제안(같은 포지션 우선) 3) 결과 리포트 '시작 전 예상' 한 줄 4) (선택) 대기실 채팅 — 각 조각 분석기 릴리스 1회.
- 위험·되돌리기: 분석기 동작이 바뀌는 릴리스라 B/P(승인 필요). 숫자가 "누가 약하다" 로 읽혀 기분 상할 수 있어 **개인 점수는 안 보이고 팀 합만** 보인다. 설정에 끄기 체크박스(기본 켬), 문제면 다음 릴리스에서 기본 끔.
- 성공 지표: 출시 2주 뒤 웹 '팽팽한 판 비율'(전력차 1 이하) 상승 · 강한 쪽 승률 61.5% → 55% 쪽으로 · 제안이 뜬 판 중 실제로 바뀐 비율(시작 전 예상 대비 실제 로스터 비교).
