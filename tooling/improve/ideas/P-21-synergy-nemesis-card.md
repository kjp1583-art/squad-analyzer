# P-21 🤝 내 시너지·천적 표 — 누구랑 하면 잘 이기고 누구한테 자주 지나
- 상태: 제안 (2026-10-11 기획 회의 차점권 20점 — 다수 효용 6 · 쉬움 6 · 사장님 방향 8)
- 한 줄: 같은 팀이면 잘 이기는 클랜원, 만나면 유독 지는 상대를 지금은 분석기 로비에서만 잠깐 볼 수 있어요. 웹 프로필에 표로 두고, 두 사람 이름을 눌러 1:1 기록(같은 팀 N판 W승 · 상대 N판 W승)도 볼 수 있게 해요.
- 누구를 위해: 협곡 30일 5판↑ 116명 중 관계가 하나라도 잡히는 93명(80%). 팀을 나누는 운영진·팀장에게도 참고용.
- 왜 지금(기획 회의 계산 · 시트 CLASSIC_NORMAL 통산, 스크림 제외·부계/닉변 통합):
  - 같은 팀으로 5판↑ 뛴 클랜원은 1인당 중앙값 31.5명, 상대로 5판↑은 42.5명(10판↑ 상대 16명). 활성 클랜원끼리 10판↑ 만난 짝이 2,060쌍.
  - 분석기 로비 기준 그대로(같은 팀 10판↑ 60%↑ 🔥 · 상대 10판↑ 30%↓ 💀) 적용하면 1인당 🔥 중앙값 2명, 💀 1명.
  - 지금 웹에는 GPTI 카드 안의 ⚔️ 천적 최대 3명(진 쪽만)뿐이고, 패치 필터를 타서 이전 기본 화면에선 활성 131명 중 25명에게만 떴다. (P-20 이후 기본이 최근 30일로 바뀌어 사정이 좋아졌는지는 출시 뒤 재확인)
  - AI 상담소 기록된 답 110건 중 14건(13%)이 사람끼리 같은 팀·맞대결 숫자를 물었다(#135 '승수 상대 전적', #136 '유미 상대 서폿', #141 '같은 팀 궁합 라인별').
- 무엇을:
  1. 프로필 🤝 카드: 🔥 잘 맞는 팀원 TOP5(같은 팀 10판↑ · 듀오 탭과 같은 수축 보정) · 💀 나를 잘 잡는 상대 TOP3 · 🎯 내가 잘 잡는 상대 TOP3. 판수를 같이 적고 '참고용' 문구.
  2. '전체 보기' — 클랜원별 표(같은 팀 판·승률 / 상대 판·내 승률 / 맞라인 판·승률, 정렬).
  3. 이름을 누르면 1:1 화면(`#p/A~B`): 같은 팀·상대·맞라인 기록과 판 목록(누르면 게임 상세).
  4. **⚠ 역시너지(같이 서면 지는 팀원)는 공개 화면에 싣지 않는다** — 탓하기 방지(분석기 로비에만 남김). 통산 기준, 스크림·탈퇴자 제외.
- 이미 있는 것과의 관계: 웹 `computeHeadToHead`/`nemesisOf`(GPTI 안 천적 3명) · 듀오시너지 탭(포지션 짝 클랜 순위) · 인간상성(맞라인 짝) · 분석기 로비 시너지·역시너지·천적 3칸(분석기 켠 사람 화면만). 이 셋을 사람 중심으로 묶어 키우는 안. 제외된 '닮은 클랜원'·'같은 팀 재대결'과 다르다.
- 시제품: 위 문구. 승인되면 `lab/P-21.html` 로 실제 데이터 미리보기부터.
- 만드는 순서: 1) 계산 함수(같은 팀 집계를 기존 천적 루프에 더함, 통산) + 프로필 카드(M) 2) 전체 표 + 정렬(S) 3) 1:1 화면 `#p/A~B`(M) 4) 2주 뒤 재측정.
- 위험·되돌리기: 탓하기로 번질 수 있음 → 역시너지 비공개 · 10판 기준 · 수축 보정 · '참고용'. 10판 표본도 ±30%p 흔들림. 웹 읽기 전용 · 새 저장 없음, 카드 숨기면 원복. LINK·탈퇴자 처리는 기존 규칙(`linkComponents`·`isDeparted`)만 쓴다.
- 성공 지표: 출시 2주 뒤 프로필 🤝 카드 펼침·1:1 화면 열람(/health links `p` 공유 포함) · AI 상담소의 같은 종류 질문 수 감소 · 디스코드 반응(탓하기 발언 0).
