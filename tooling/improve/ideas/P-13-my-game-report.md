# P-13 📋 이름 안 불린 8명을 위한 '내 판 성적표'
- 상태: 제안
- 한 줄: 결과 리포트는 MVP·ACE·역적만 부르는데, 분석기가 **내 화면에만** "이번 판 시야는 클랜 정글 상위 15% · CS는 내 평소보다 ▼0.8" 같은 3줄을 보여 줘요. 진 판에도 잘한 점 하나는 꼭 짚어 줘요.
- 누구를 위해: 분석기를 켜고 협곡 내전을 뛰는 클랜원 전원. 특히 매 판 아무 평가도 못 받는 대다수.
- 왜 지금(2026-10-04 일요일 기획 회의 · 시트 CLASSIC_NORMAL 실측):
  - 7/27 이후 사람-판 12,760건 중 매치평가 '평가 없음' **10,120건(79.3%)** — MVP 1,275 · ACE 1,276 · 역적 89. 진 쪽 6,380건 중 **5,015건(78.6%)은 아무 말도 못 듣는다.**
  - 재료는 이미 시트 '지표' 칸에 있다(6/12~ 17,827건). 같은 라인 15판↑ 지표가 있는 사람-라인 조합 256개(128명) — '내 평소' 계산 가능.
  - 라인별 분포가 크게 달라 **라인마다 따로** 비교해야 한다: CS/분 중앙값(상위10%) 탑 7.0(8.7) · 정글 6.4(8.0) · 미드 7.1(8.7) · 원딜 8.2(9.7) · 서폿 1.0(1.4) / 킬관여 중앙값 탑 40% · 정글 59% · 서폿 60% / 시야/분 서폿 3.28 · 나머지 0.89~1.23.
  - 회의 심사 3관점(다수 효용 · 만들기 쉬움 · 사장님 방향) 합계 22점으로 후보 8개 중 1위.
- 무엇을: 분석기 결과 리포트 창(`_show_match_report`) 맨 아래, **분석기 사용자 본인** 블록
  1. 이번 판 지표(CS/분·킬관여·시야/분·딜량·골드)를 **같은 라인 클랜 분포**에 대어 상위 n% — 가장 잘한 것 1개 + 가장 아쉬운 것 1개만.
  2. **내 이 라인 최근 20판 중앙값** 대비 ▲▼ (이 라인 15판 미만이면 줄 생략).
  3. 진 판은 잘한 지표 먼저, 이긴 판은 아쉬운 지표 먼저.
  - 분포는 `_build_clan_index` 스캔 때 같이 만든다(gviz 캐시 — 시트 호출 추가 없음). 공개 채널·웹에는 올리지 않는다.
- 이미 있는 것과의 관계: 결과 리포트 MVP·ACE·역적·판 업적(극단 조건만) / 분석기 기록 탭(누적 리더보드) / 웹 선수 페이지 '지표 평균'(통산) / P-1 '개인 최고 경신'(신기록 때만) — 모두 '이번 한 판·평가 없는 79%' 를 다루지 않는다.
- 시제품: 문구 예시
  ```
  📋 내 판 성적표 — 정글 · 패배
  👍 시야 1.42/분 — 클랜 정글 상위 15% (내 평소 1.05 ▲)
  🔧 CS 5.1/분 — 클랜 정글 하위 30% (내 평소 6.2 ▼1.1)
  -# 같은 라인끼리만 비교해요 · 나에게만 보여요
  ```
- 만드는 순서: 1) 라인별 분포·개인 최근 20판 계산(분석기 인덱스 스캔에 덧붙임 · 단위 테스트) 2) 결과 리포트 블록 3) 설정 끄기 체크박스 — 분석기 릴리스 1~2회.
- 위험·되돌리기: 분석기 동작이 바뀌는 릴리스(승인 필요). '하위 30%' 가 기분 상할 수 있어 아쉬운 점은 1개만·부드러운 말투, 설정에서 끄기(기본 켬). 지표 칸이 빈 판은 블록 생략.
- 성공 지표: 출시 2주 뒤 설정에서 끈 비율(낮을수록 좋음) · 분석기 실행 대수 유지/증가 · 클랜원 반응(디스코드·주간스쿼드 댓글).
