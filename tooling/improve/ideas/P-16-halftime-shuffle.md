# P-16 🔀 하프타임 섞기 — 같은 10명끼리만 도는 밤을 줄이자
- 상태: 제안
- 한 줄: 대기실이 둘 이상 도는 밤, 밤 중간(예: 22:30 · 각 방 3판째 끝)에 봇이 "방 섞을래요?" 를 묻고, 누르면 지금 남은 사람들로 **전력이 맞는 새 두 방**을 제안해요. 안 누르면 아무 일 없어요.
- 누구를 위해: 대기실이 여러 개 도는 밤의 클랜원 전원(하룻밤 보통 44명). 특히 늘 같은 방에만 있게 되는 새내기·조용한 클랜원.
- 왜 지금(2026-10-07 시트 CLASSIC_NORMAL 8/1~ 실측, '정오 기준 밤'):
  - 4판↑ 열린 밤 68일 중 **63일은 대기실이 2개 이상 동시에** 돌았다(25분 안에 시작, 겹치는 사람 2명 이하).
  - 하룻밤 참가자 중앙값 **44명**인데, 이어지는 판(50분 안)의 **46.5%(540/1,162)가 직전 판과 10명 중 8명↑ 같은 구성** — 방이 여러 개여도 같은 무리끼리만 계속 돈다.
  - P-7(새내기 첫 3판)·보류된 P-8(조용히 사라지는 단골)이 가리킨 '섞이지 못함' 문제를 운영 쪽에서 직접 푸는 방법. 10/4 기획 회의 후보(심사 미완)였던 것을 숫자로 다시 확인.
- 무엇을:
  1. **봇 한 줄 제안**(내전 채널 · 하룻밤 1회): 동시에 도는 방이 2개↑이고 각 방이 3판째를 끝냈을 때 "🔀 하프타임 — 방을 섞어 볼까요? [섞기 제안 보기]" 버튼.
  2. 누르면(운영진·방장만) 지금 두 방에 있는 사람(최근 판 로스터)으로 **전력 합이 맞고 주포지션이 겹치지 않게** 두 방 편성안을 임베드로 — 봇 기존 `balance_lobbies`(조편성) 재사용. 오늘 같은 방이었던 사람끼리는 되도록 갈라 놓는다.
  3. 강제하지 않는다: 이동은 사람이 롤에서. 거절하면 그날은 다시 묻지 않는다.
  4. 웹 '오늘 밤' 카드(단골 예보 옆)에 "오늘 새로 같이 뛴 사람 n명" 한 줄 — 효과를 눈으로 보이게.
- 이미 있는 것과의 관계: 봇 `balance_lobbies`/조편성(내전 시작 전 1회, 출석판은 꺼져 있음) · 분석기 5:5 팀짜기·P-12 맞바꾸기(**한 방 안**에서의 균형) — P-16 은 **방과 방 사이** 섞기, 밤 중간에 한 번.
- 시제품: 문구 예시
  ```
  🔀 하프타임! 지금 방 2개가 3판씩 돌았어요. 섞어서 새 얼굴과 붙어 볼까요?   [섞기 제안 보기]
  ── (누르면) ──
  🅰 방  탑 ○○ · 정글 ○○ · 미드 ○○ · 원딜 ○○ · 서폿 ○○   (전력 합 52.1)
  🅱 방  …                                                    (전력 합 51.8)
  -# 오늘 같은 방이었던 사람끼리 7쌍 → 2쌍 · 이동은 롤 대기실에서 · 안 섞어도 괜찮아요
  ```
- 만드는 순서: 1) 지표만 먼저 — 웹 '오늘 새로 같이 뛴 사람' 한 줄 + 주간스쿼드 사실(같은 무리 비율)(S) 2) 봇 하프타임 버튼 + 편성안(M) 3) 2주 지표 보고 문구·시각 조정.
- 위험·되돌리기: 운영 방식에 손대는 일이라 **사장님·운영진 판단이 먼저**. 친한 사람끼리 노는 재미를 깨면 역효과 — 그래서 버튼·하룻밤 1회·거절 시 끝. 봇 설정으로 끄기.
- 성공 지표: 출시 2주 뒤 '직전 판과 8명↑ 같은 구성' 비율 46.5% → 40% 아래 · 오늘 새로 같이 뛴 사람 수 중앙값 · 새내기(P-7 대상)의 둘째 주 재방문.
