# P-28 🔎 통합 검색 — 검색창에 챔피언·화면 이름·날짜도 치면 바로 간다
- 상태: 제안 (2026-10-18 기획 회의 21점 후보 · 10/22 코드로 재확인)
- 한 줄: 웹 맨 위 검색창은 지금 **소환사 닉네임과 게임ID**만 찾아요. '리신'·'인간상성'·'10/11' 을 쳐도 해당 챔피언 상세·그 화면·그날 판들로 바로 가게 하고, 자동완성 목록을 「👤 사람 / 🛡 챔피언 / 📂 화면 / 📅 날짜」 묶음으로 보여 줘요.
- 누구를 위해: 웹 방문자 전체 — 챔피언 176종(최근 30일)과 메뉴 18개가 새로 검색되는 대상.
- 왜 지금:
  - **코드 확인(10/22)**: `onType()` 은 `findPlayers(q,8)` 결과만 자동완성에 올리고(`renderSuggest` 는 사람 줄만 그린다), 입력창 안내문은 「소환사명 또는 게임ID 검색」이다 — 챔피언·화면·날짜는 어디에도 없다. 챔피언 검색은 장인랭킹 안(`mstQ`, '갱플·gang' 별칭 지원)에만 있다.
  - 회의 계산(CLASSIC 20,216행): 챔피언 184종 중 30일 기준 티어표에 오르는 건 8판↑ 132종(75%) — 나머지 26종은 접힌 '표본 부족' 목록 안이라 상세로 들어가려면 한참 내려야 한다.
  - **이름 충돌**: 챔피언 이름 184개 중 **15개가 클랜원 닉네임에 그대로 들어 있다**(예: '진'은 361판 챔피언인데 닉 4명과 겹침, '아리' 184판·닉 3명). 지금 '진'을 치면 챔피언이 아니라 사람 프로필로 바로 간다.
  - 사장님이 반복해서 '검색'을 지적했다(8/12 지시: 새 패치 날 검색이 안 된다 → 검색은 패치 필터를 안 탄다). 검색은 첫 화면 가장 위, 모든 방문이 지나는 길이다.
- 무엇을:
  1. 자동완성을 묶음으로: 👤 사람(최대 3~5) · 🛡 챔피언(3) · 📂 화면(3) · 📅 날짜(1). 묶음 이름을 보여 줘서 '진' 같은 충돌을 사용자가 고르게 한다.
  2. 챔피언 선택 → `#c/챔피언`(champlog 상세). 영문·초성·별칭은 `mstQ` 로직 재사용(분석기 `_NB_ALIAS`: 블츠·미포 등은 웹에 연결).
  3. 화면 이름('인간상성'·'내부티어'·'듀오') 선택 → 그 탭. '10/11'·'2026-10-11' 입력 → 그날 판 목록(어젯밤 카드 방식).
  4. **엔터만 눌렀을 때**는 지금처럼 사람이 먼저 — 챔피언은 정확히 일치할 때만 승격. 안내문은 「사람·챔피언·메뉴 검색」.
- 이미 있는 것과의 관계: 웹 `findPlayers`(사람·게임ID) · `mstQ`(장인랭킹 안 챔피언 검색) · 분석기 챔피언 별칭 `_NB_ALIAS`. P-24(전적 필터 칩)·P-25(클랜원 도감)와 겹치지 않는다.
- 시제품: 자동완성 묶음 예시
  ```
  [진]
  👤 진짜루   9판 55% · 진심으로#KR  …
  🛡 진 (원딜) 361판 51%
  📂 (없음)
  ```
  승인되면 `lab/P-28.html` 에 실제 시트로 도는 검색창 미리보기부터.
- 만드는 순서: 1) 챔피언 묶음 + `#c/` 이동 + 충돌 순서 규칙(웹 · S) 2) 화면 이름·날짜 묶음(S) 3) 별칭 연결 · 폰 키보드 높이 대응(S) 4) 2주 뒤 재측정.
- 위험·되돌리기: 닉네임·챔피언 이름이 겹칠 때 순서 판단 → 묶음 이름으로 해소. 자동완성이 길어지면 폰 키보드에 가림 → 묶음마다 3개 제한. 웹 읽기 전용 · 기존 검색 로직 위에 묶음만 더해서 원복 쉬움.
- 성공 지표: P-26 계기판이 있으면 검색 사용 수(사람 vs 챔피언·화면·날짜 비율) · '검색해도 안 나온다' 류 제보 수.
