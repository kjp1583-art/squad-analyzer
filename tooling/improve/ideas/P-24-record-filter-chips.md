# P-24 🧲 전적 목록 필터 칩 — "리신만 · 정글만 · 패배만" 눌러서 골라 보기
- 상태: 제안 (2026-10-18 일요일 기획 회의 공동 1위권 22점 — P-23 프로필 탭 배포 뒤 자연스러운 다음 조각)
- 한 줄: 프로필 전적 탭은 최신순으로 20판씩 더 불러오는 방식뿐이라 "내 리신 판만" 같은 걸 보려면 더보기를 여러 번 눌러야 해요. 결과(승·패) / 라인 / 챔피언 칩을 눌러 골라 보고, 고른 조건의 판수·승률·평균 KDA를 한 줄로 보여 줘요.
- 누구를 위해: 프로필을 보는 클랜원 — 최근 30일 활동자 187명 중 20판 넘기는 79명(42%) · 통산 60판↑ 102명 · 100판↑ 65명 · 200판↑ 27명.
- 왜 지금(회의 에이전트 계산 · CLASSIC_NORMAL PUUID별, 확정 결과만):
  - 통산 60판↑ 102명의 사용 챔피언은 중앙값 **33종**(상위 10% 55종), 포지션 중앙값 5개.
  - 각 챔피언의 '3번째로 최근 판'이 최신순 목록에서 **중앙값 69번째, 상위 25% 126번째** — 89.5%가 20번째 밖. 특정 챔피언 판을 찾으려면 '20판 더'를 3~6번 눌러야 한다.
  - 직전에 배포된 A-30·P-23(20판씩 보기·프로필 탭)이 목록을 짧게 시작하게 만들었으므로, "원하는 판만 고르기"가 비어 있는 다음 칸이다.
  - 이미 있는 목록 도구: 전적은 `pmListHtml`(`_pmLimit` 20씩) · 내전기록은 `LOG_LIMIT` 60씩 더보기뿐 — 필터는 없다(grep `pmFilter|이 챔피언만` 0건).
- 무엇을:
  1. 전적 탭 맨 위 칩 줄: **결과**(전체·승·패) / **라인**(탑·정글·미드·원딜·서폿) / **챔피언**(그 사람이 많이 쓴 순 8개 + '＋더보기').
  2. 고른 조건 요약 한 줄: "정글 · 리신 23판 61% · 평균 KDA 3.1". 10판 미만은 흐리게(소표본 오해 방지).
  3. 챔피언 탭에서 챔피언을 누르면 전적 탭이 그 챔피언으로 걸린 채 열린다.
  4. 내전기록 화면에도 같은 칩 + '날짜로 이동'.
  5. 주소에 필터를 넣어(`#p/닉/전적?c=리신`) P-2 공유 링크와 이어 쓴다.
  - 계산: 기존 `_pmList` 만 거르고 `matchCard` 는 그대로. 새 저장 없음.
- 이미 있는 것과의 관계: P-3 라인·픽 카드(통계 카드) · P-23 프로필 탭(구조) · A-30 20판씩 보기 — 전부 '목록을 걸러 주는' 기능은 아니다. 챔피언 장인랭킹 상세의 '사용된 게임'은 챔피언 쪽 목록.
- 시제품: 칩 줄 구성(위 1~2). 승인되면 `lab/P-24.html` 에 실제 시트로 도는 폰 전적 탭 미리보기부터.
- 만드는 순서: 1) 결과·라인·챔피언 칩 + 요약 줄(웹 · S) 2) 챔피언 탭 연결 + 주소 필터(S) 3) 내전기록 칩(S) 4) 2주 뒤 재측정.
- 위험·되돌리기: 필터를 건 뒤 '더보기' 개수와 해시가 어긋나지 않게 `_pmLimit` 초기화 필요 · 소표본 승률 강조 금지 · 챔피언 칩 8개 제한(폰 줄 길이). 웹 읽기 전용 · 칩 줄만 숨기면 원복.
- 성공 지표: 출시 2주 뒤 필터 칩 사용(주소 `?c=`·`?r=` 공유 수는 /health links 로 못 재므로 칩 클릭 카운터를 같은 커밋에 파일 누적) · 전적 탭의 '20판 더' 평균 클릭 수 감소.
