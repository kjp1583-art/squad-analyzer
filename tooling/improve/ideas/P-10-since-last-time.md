# P-10 🔄 지난번 대비 — 내 프로필에 "저번에 오신 뒤로" 한 줄
- 상태: 승인 대기 (2026-10-01 기획 회의)
- 한 줄: 웹에서 내 프로필을 열면 "마지막으로 보신 9일 전부터 12판 · 7승 5패 · 서폿 승률 +4%p · 새 챔프 2종"을 한 줄로 보여 줍니다. 브라우저에만 저장해서 서버·시트에는 아무것도 안 남습니다.
- 누구를 위해: AI 상담소 답변 104건 중 **41건(39%)** 이 '지난번에', '저번에', '그 뒤로' 처럼 이전 답과 비교합니다. 예: #177 "지난번에 봤을 땐 서른세 판이었는데 이제 71판", #113 "먼저 지난번 약속부터. 18대결이었고 지금 23대결", #182 "이기는 법은 지난번에 이미 말했고, 이번엔 그게 지켜졌는지". 같은 사람이 변화를 보려고 3P를 내고 다시 묻습니다.
- 왜 지금:
  - 정규식으로 센 값이라 일부는 '아까'·'그때' 같은 일반 표현일 수 있습니다(상한). 확실한 '이전 답 대비' 표현만 골라도 #113·#118·#174·#176·#177·#181·#182·#183·#191·#196·#197·#198 등 12건 이상.
  - 변화가 궁금한 사람은 많은데 웹에는 시간 흐름이 **그래프**(성장 곡선·월별/판수 구간)로만 있고, "지난번 이후 달라진 것"을 말로 주는 곳이 없습니다.
  - 질문은 3P·최대 1시간 대기(P-3 기획안 근거)이고 8/4에는 운영비 때문에 상담소가 며칠 멈췄습니다. 이 한 줄은 무료·즉시입니다.
  - 새 데이터·시트·봇이 필요 없습니다: 기존 `localStorage` 방문 스냅샷 습관(`rawCacheGet`, 10950행 부근)과 같은 방식입니다.
- 무엇을:
  - 프로필 맨 위(이름 아래) 한 줄 칩. 처음 오는 브라우저는 표시 없음("다음에 오시면 달라진 점을 알려드려요" 작은 글씨 1회).
  - 보여 줄 것(3개까지, 변화가 큰 순): 판수·승패 / 라인별 승률 변화(5판 이상 늘어난 라인만) / 새로 해 본 챔피언 / 연승·연패 기록. 변화가 없으면 "저번과 같아요".
  - 내용은 사실 숫자만, 7일 미만 재방문은 표시 안 함(반복 방문 때문에 의미 없는 줄 방지).
  ```

  [지금 기준으로 다시 저장]
  ```
  - 저장: `localStorage['sgg_seen:{닉네임}']` = {시각, 판수, 승, 라인별 판/승, 챔프 집합} 만. 닉네임별, 브라우저별. 로그인 불필요, 서버 전송 없음, 생년·개인정보 없음.
- 이미 있는 것과의 관계: 성장 곡선(월별/판수 구간, `setGrowthSpan`)은 그림, 이 한 줄은 **내가 본 시점 기준 문장**입니다. P-1 기록실(한 판 최고 기록)·P-3 라인·픽 카드와 같은 프로필에 붙지만 계산이 겹치지 않고, P-3의 라인별 집계를 재사용하면 라인 변화도 거의 공짜입니다.
- 만드는 법: `index.html` `renderPlayer` 위쪽에 `sinceLastHtml(name)` 하나 + 방문 저장 1줄, `_funMemo` 로 캐시. try/catch 로 저장 실패(비공개 창)는 조용히 생략(CLAUDE.md 의 browser storage 규칙). 탈퇴자·타인 프로필에도 '본 사람의 브라우저 기준'이라 문제 없음(내 프로필이 아니어도 "내가 본 뒤로"). 패치노트·`BUILD_ID`.
- 위험·되돌리기: 여러 기기·시크릿 창에서는 비교가 안 보임(기능 소실이지 오류 아님). 남의 프로필에도 뜨는 점은 오히려 "라이벌이 저번보다 어땠나"로 쓰일 수 있어 의도적으로 허용. 한 줄 제거 + `BUILD_ID` 올리면 원복, 서버 흔적 없음.
